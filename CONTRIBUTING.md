# Contributing to DoneProof

1. Check existing issues or open an issue describing the proposed change.
2. Create a branch named `feat/<short-description>` or `fix/<short-description>`.
3. Make a focused change and add or update tests.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request describing the change, evidence, and test results.
6. Request review from a teammate before merging.

Do not submit secrets, personal data, or untrusted repositories for execution. The current prototype does not run commands supplied by task files.
